Problem Statement & Executive Vision

Addressing campus operational silos with unified instrumentation

Overview

The Operational Challenge

  • Fragmented Systems: Academic attendance, fee ledgers, and timetables operate in isolated software silos.
  • Delayed Risk Detection: At-risk students drop below threshold before intervention can occur.
  • Subpar Mobile Experience: Legacy portals lack responsive mobile cockpit layouts for active faculty marking.

The PulseGrid Solution

  • Unified Role-Aware Cockpit: Single dashboard tailored dynamically for Admins, Teachers, and Students.
  • Automated AI Risk Engine: Instant weighted scoring analyzing attendance drops, fee delays, and lateness.
  • Mobile-First Instrumentation: Fast, offline-capable UI with 44px tap targets and optimistic state sync.

System Architecture & Tech Stack

Modern production-ready full-stack web application

Architecture

Frontend Core

  • Next.js 15 (App Router): Server Components by default for optimal performance.
  • React 19 & TypeScript 5: Strict type safety with noUncheckedIndexedAccess.
  • Tailwind CSS 4: Modern design system with custom CSS variables.

State & Cache

  • Redux Toolkit: Centralized slices for auth, attendance, finance, and schedules.
  • TanStack Query v5: 30s background refetching with tab visibility pausing.
  • React Hook Form + Zod: Strict runtime input schema validation.

Deployment & API

  • Vercel Serverless: Built-in /api/data/* route handlers serving datasets.
  • Local Mock API: JSON Server (db.json) running via concurrently.
  • PWA Shell: Manifest, favicon ICO/SVG, offline page fallback.

AI-Powered Risk Scoring Engine

Proactive student intervention through weighted operational analytics

AI Analytics

Risk Formula Specification

The operational risk engine calculates student vulnerability using a normalized weighted equation:

Risk Score = (1 - AttendanceRate) * 0.5
             + OverdueFeeRatio * 0.3
             + LatenessFactor * 0.2
  • Low Risk Tier (Score < 0.25): Normal academic standing.
  • Medium Risk Tier (0.25 - 0.40): Flagged for advisor check-in.
  • High Risk Tier (Score > 0.40): Urgent intervention watchlist.

Key Capabilities

  • Boundary Testing: Fully validated against edge cases (100% attendance, zero fees).
  • Dual Fallback Execution: Evaluates via serverless API (/api/risk) with client-side offline execution fallback.
  • Real-Time Watchlist: Displays priority intervention alerts directly on the Admin & Teacher dashboard.
